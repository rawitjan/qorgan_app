# Qorgan (Қорған) — Платформа цифровой безопасности и превентивной защиты

**Qorgan** (от каз. *Қорған* — щит, крепость, защита) — комплексное веб-приложение для мониторинга цифровых угроз, превентивного выявления мошенничества и интерактивного обучения кибергигиене.

Архитектура системы построена с учетом двух ключевых пользовательских сценариев (**Junior** для детей и подростков и **Standard** для взрослой аудитории/специалистов), а также включает корпоративное рабочее пространство (**Organization Workspace**) для школ, университетов и компаний.

## 🚀 Ключевые возможности

1. **Многоуровневый анализ подозрительного контента (Qorgan Lens):**
* Проверка входящих сообщений, подозрительных ссылок, скриншотов переписок, фишинговых сайтов и сомнительных предложений заработка (дропперство, скам-лотереи, фейковые инвест-платформы).
* Классификация уровня риска: `SAFE`, `SUSPICIOUS`, `DANGEROUS`, `CRITICAL`.
* Автоматическая генерация рекомендаций по защите и юридических справок (статьи УК РК, алгоритм обращения в киберполицию).


2. **Адаптивный UX (Junior Mode & Standard Mode):**
* Переключение интерфейса «на лету» через React Context.
* Упрощенные визуальные метафоры, геймифицированные карточки и дружелюбный тон для детей.
* Детализированная телеметрия, индикаторы компрометации (IoC) и протоколы безопасности для опытных пользователей.


3. **Практический тренажер ситуаций (Training Simulator):**
* Разбор реальных сценариев: кибербуллинг, вымогательство, фишинг в мессенджерах, дроп-схемы, учетные данные и двухфакторная аутентификация.
* Пошаговые решения с ветвлением выбора и оценкой последствий.
* Дерево навыков (*Skill Journey*), стрик активности (*Streak Indicator*) и интегральный индекс защищенности (*Qorgan Score*).


4. **B2B / B2G контур (Organization Workspace):**
* Профиль киберустойчивости класса, студенческой группы или отдела компании.
* Мониторинг прохождения обучающих треков и выявление слабых мест коллектива.


5. **Презентационный модуль (`/pitch`):**
* Полноценная встроенная презентация стартапа с поддержкой навигации с клавиатуры для питчей перед жюри хакатонов, грантодателями и инвесторами.

## 🔄 Режимы работы: Standard vs Junior

Приложение спроектировано вокруг контекста восприятия пользователя (`ModeContext`). Логика отображения меняет не только стили, но и терминологию, сложность вердиктов и структуру рекомендаций:

| Параметр | Standard Mode | Junior Mode |
| --- | --- | --- |
| **Целевая аудитория** | Взрослые, студенты, специалисты | Дети 8–14 лет, школьники младших и средних классов |
| **Визуальный стиль** | Строгий нео-минимализм, четкая плотность данных, таблицы и индикаторы метрик | Крупные карточки, яркие акцентные бейджи, игровая графика, понятные иконки |
| **Вердикт сканера** | Технические детали, категории риска, юридическая квалификация правонарушения | Понятный совет («Не нажимай», «Расскажи родителям»), похвала за бдительность |
| **Геймификация** | Уровень киберграмотности, индекс компрометации, закрытие корпоративных модулей | Очки опыта (XP), бейджи достижений, анимации стрика («Огонь дня»), квесты |
| **Экстренные действия** | Контакты регуляторов, блокировка счетов, заявление в правоохранительные органы | Кнопка вызова помощи, звонок родителю или на доверенный номер поддержки |

## 🧩 Функциональные модули платформы

### 1. Qorgan Lens (Сканер угроз)

Ядро превентивной безопасности приложения. Находится в `src/components/qorgan/lens-scanner.tsx` и управляется хуком `use-lens-scanner.ts`.

* **Входные данные:** текст сообщения, ссылка (URL), описание ситуации или скриншот.
* **Обработка:** эвристический и семантический анализ шаблонов мошенничества, проверка доменных зон, выявление социальной инженерии и психологического давления.
* **Результаты анализа:**
* `LensResultStandard`: подробная раскладка по векторам атаки, затронутым статьям законодательства (`LegalRecommendation`) и прямым шагам реагирования (`SafetyAction`).
* `LensResultJunior`: фокус на простом правиле «Что делать прямо сейчас» + разбор уловки мошенников простым языком.
* `EmergencyAlert`: всплывающий критический алерт при обнаружении непосредственной угрозы жизни, здоровью, шантажа или хищения финансов.
* `LensHistory`: журнал предыдущих проверок с возможностью повторного просмотра отчетов.



### 2. Интерактивный симулятор обучения (Training Hub)

Компоненты расположены в `src/components/training/`.

* `training-home.tsx` — каталог интерактивных сценариев, сгруппированных по категориям (социальные сети, банкинг, онлайн-игры, мессенджеры).
* `scenario-player.tsx` — пошаговый плеер с имитацией переписки или веб-страницы. Пользователю предлагается сделать выбор в критический момент атаки.
* `scenario-result.tsx` — детальный разбор ошибок и начисление баллов к навыкам.
* `skills-view.tsx` & `skill-journey.tsx` — профиль прокачки компетенций (распознавание фишинга, цифровая гигиена, защита персональных данных, противодействие буллингу).
* `achievements-view.tsx` — витрина разблокированных бейджей за закрытие модулей.

### 3. Монитор угроз (Threat Pulse)

Компонент `src/components/pulse/threat-pulse-view.tsx`.

* Сводка актуальных волн атак и схем мошенничества в регионе (Казахстан и СНГ).
* Карточки угроз (`ThreatCard`) с описанием механики, уровня опасности и превентивных мер.

### 4. Корпоративный кабинет (Organization Workspace)

Компонент `src/components/organization/organization-workspace.tsx`.

* Управление профилем учебного заведения или компании.
* Таблица участников, статистика прохождения обязательных симуляций, тепловая карта уязвимостей коллектива.
* Экспорт сводных отчетов по уровню защищенности.

### 5. Интегрированный Pitch Deck

Страница `src/app/pitch/page.tsx` (`pitch-deck.tsx` и `pitch-slides.tsx`).

* Полноэкранные интерактивные слайды: Проблема рынка ➡️ Решение Qorgan ➡️ Технологическая архитектура ➡️ Бизнес-модель ➡️ Анализ конкурентов ➡️ Дорожная карта и команда.
* Поддерживает переключение клавишами клавиатуры (`←` / `→` / `Space`), полноэкранный режим и быстрый возврат в рабочую среду приложения.

## 🛠 Архитектура и стек технологий

```
┌─────────────────────────────────────────────────────────┐
│                    Next.js App Router                   │
│         / (Main Application)    |    /pitch (Pitch Deck)│
└────────────────────────────┬────────────────────────────┘

       ┌─────────────────────┴─────────────────────┐
       ▼                                           ▼
┌──────────────────────────┐             ┌──────────────────┐
│   Layout & Navigation    │             │   Mode Context   │
│ AppShell / DesktopHeader │             │ Standard / Junior│
│ MobileHeader / BottomNav │             └─────────┬────────┘
└──────────────┬───────────┘                       │
               │                                   │
       ┌───────┴───────────────────────────────────┴───────┐
       ▼                                                   ▼
┌──────────────────────────────┐            ┌─────────────────────────────┐
│       Feature Domains        │            │        Custom Hooks         │
│ • Dashboard (Std / Junior)   │◄───────────┤ • useDashboardData()        │
│ • Qorgan Lens (Scanner/Res)  │            │ • useLensScanner()          │
│ • Training Hub (Scenarios)   │            │ • useTraining()             │
│ • Threat Pulse (Feed)        │            │ • useOrganization()         │
│ • Organization Workspace     │            └──────────────┬──────────────┘
│ • User Profile               │                           │
└──────────────┬───────────────┘                           │
               │                                           │
               ▼                                           ▼
┌──────────────────────────────┐            ┌─────────────────────────────┐
│   UI Kit (Radix / Tailwind)  │            │     Data / API Mock Layer   │

│ Progress, Badge, Tabs, Toast │            └─────────────────────────────┘
└──────────────────────────────┘

```

* **Фреймворк:** [Next.js](https://www.google.com/search?q=https://nextjs.org/) (версия 15+, App Router, SSR/CSR гибридная модель).
* **Язык программирования:** TypeScript со строгой статической типизацией (`strict: true`).
* **Стилизация:** [Tailwind CSS](https://www.google.com/search?q=https://tailwindcss.com/) с поддержкой темной/светлой темы, адаптивной верстки под мобильные и десктопные экраны.
* **UI Примитивы:** Архитектура компонентов на основе паттернов [Radix UI / shadcn/ui](https://www.google.com/search?q=https://ui.shadcn.com/) (доступность a11y, клавиатурная навигация, фокус-трапы).
* **Иконки:** Векторные SVG-иконки и тематические наборы (`qorgan-icon`, `risk-icon`, `skill-icon`).
* **Шрифты:** Geist Sans / Geist Mono (или системные Sans-шрифты через `next/font`).

## 💻 Установка и запуск

### Системные требования

* **Node.js:** версия `18.18.0` или выше (рекомендуется LTS 20.x).
* **Пакетный менеджер:** `npm`, `pnpm` или `yarn`.

### Шаги установки

1. **Клонирование репозитория:**
```bash
git clone https://github.com/your-username/qorgan_app.git
cd qorgan_app

```


2. **Установка зависимостей:**
```bash
npm install
# или с использованием pnpm:
# pnpm install

```


3. **Запуск в режиме локальной разработки:**
```bash
npm run dev

```


Приложение запустится по адресу: [http://localhost:3000](http://localhost:3000).
4. **Просмотр презентации стартапа (Pitch Deck):**
Откройте в браузере: [http://localhost:3000/pitch](http://localhost:3000/pitch).
5. **Сборка production-бандла:**
```bash
npm run build
npm run start

```

## 🔌 Интеграция с реальным бэкендом и LLM

В текущей версии вызовы к данным инкапсулированы в модуле `src/lib/api.ts` и эмулируются с реалистичными задержками ответов сети. Для подключения реального AI-сервиса (на базе OpenAI API, Google Gemini API, Claude API или локальной модели Ollama):

1. **Создайте файл `.env.local`:**
```env
NEXT_PUBLIC_API_BASE_URL=https://api.qorgan.kz/v1
QORGAN_AI_API_KEY=your_secure_api_key_here
QORGAN_AI_MODEL=gemini-1.5-pro # или gpt-4o-mini

```


2. **Замените мок в `src/lib/api.ts` на реальный HTTP-клиент:**
```typescript
export async function analyzeContentWithQorgan(
  content: string, 
  type: 'text' | 'url' | 'image'
): Promise<ScanResult> {
  const response = await fetch('/api/lens/analyze', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ content, type }),
  });

  if (!response.ok) {
    throw new Error('Ошибка анализа контента на стороне сервера');
  }

  return response.json();
}

```


3. **Формат системного промпта для ИИ-анализатора:**
При развертывании серверного эндпоинта `/api/lens/analyze` рекомендуется отправлять системную инструкцию с жестким требованием возвращать ответ строго в формате JSON, соответствующем интерфейсу `ScanResult`, с обязательной локализацией на казахский и русский языки.
